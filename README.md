# Personal Portfolio Website

### A personal portfolio showcasing my projects, experience, technical skills, and growth as a software developer.

[🔗 Live Demo](https://vasavi-portfolio-beta.vercel.app/)

---

## 📋 Overview

This is my personal portfolio website, built to showcase my work, technical experience, projects, certifications, and development journey.

The portfolio is designed with a dark, minimal, and editorial visual style, with subtle animations and interactive elements throughout the experience.

---

## ✨ Key Features

- **Home Section** - Introduction, role, and quick access to my work and resume.
- **About Section** - Background, technical skills, and development focus.
- **Projects Section** - Selected projects with detailed descriptions, technologies, and project highlights.
- **Experience Section** - Professional experience and internships.
- **Certifications Section** - Technical certifications, courses, and training.
- **Contact Section** - Professional contact information and social links.
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices.
- **Interactive UI** - Subtle animations and hover interactions for a polished experience.

## 📂 Featured Projects

### Woven

A full-stack bookmark manager designed to organize bookmarks into collections with authentication, search, favorites, and smart link previews.

**Tech:** Next.js, TypeScript, PostgreSQL, Prisma, Clerk, Zod, Cheerio, Cloudinary

---

### BloomIn

A full-stack storefront application designed for small shopkeepers, featuring customer and seller workflows, cart and order management, seller dashboards, and a QR-based storefront.

**Tech:** Next.js, TypeScript, Node.js, Express.js, PostgreSQL

---

### Pawsitive Pursuit

A responsive browser game built with JavaScript featuring custom illustrations, animations, branching game logic, and multiple possible endings based on player decisions.

**Tech:** HTML5, CSS3, JavaScript
